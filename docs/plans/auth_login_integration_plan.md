# Login Integration & AppAuth Setup

Implement Username/Password and Google Login flows, utilizing `AppAuth` for Google Login OIDC state management and automatic token refresh, with strict adherence to Clean Architecture.

### Domain Layer (100% Pure Kotlin)

#### [NEW] `OidcAuthConfig.kt`
- Data class containing the authorization endpoint, token endpoint, client ID (`mobile-api`), and redirect URI. 

#### [NEW] `AuthTokens.kt`
- Data class containing `accessToken`, `refreshToken`, `idToken`, `expiresIn`, and `refreshExpiresIn`.

#### [NEW] `LoginWithEmailUseCase.kt`
- Delegates to `IAuthRepository.loginWithEmail(email, password)`.

#### [NEW] `GetOidcAuthConfigUseCase.kt`
- Returns the `OidcAuthConfig` so the Presentation Layer can construct the AppAuth Intent locally.

#### [NEW] `SaveGoogleLoginTokensUseCase.kt`
- Takes the `AuthTokens` generated by AppAuth in the Presentation Layer and passes them to `IAuthRepository.saveTokens(authTokens)` to be persisted.

### Data Layer — Token Storage & API

#### [NEW] `IAuthTokenLocalDataSource.kt` & `AuthTokenLocalDataSourceImpl.kt`
- Uses `DataStore<Preferences>` to store a single string: the serialized AppAuth `AuthState` JSON (`authState.jsonSerializeString()`).

#### [MODIFY] [AuthApiService.kt](file:///home/yousef/Desktop/NutriScan/data/src/main/kotlin/iti/grad/nutriscan/data/remote/api/AuthApiService.kt)
- Add a new Keycloak specific Retrofit service: `KeycloakApiService`.
- `@POST("realms/nutriscan/protocol/openid-connect/token")`
- `@FormUrlEncoded` with `grant_type="password"`, `client_id="mobile-api"`, `username`, and `password`.
- Returns a custom `KeycloakTokenResponseDto` containing the tokens and expiry times.

#### [MODIFY] [AuthRepositoryImpl.kt](file:///home/yousef/Desktop/NutriScan/data/src/main/kotlin/iti/grad/nutriscan/data/repository/AuthRepositoryImpl.kt)
- **Username/Password (`loginWithEmail`)**: 
  - Call `KeycloakApiService.loginWithEmail()`.
  - On success, map the response tokens to a manual AppAuth `TokenResponse`.
  - Construct an `AuthState` object from this `TokenResponse` and save it to `AuthTokenLocalDataSource`.
- **Save Tokens (`saveTokens`)**:
  - Takes pure domain `AuthTokens`, constructs an AppAuth `TokenResponse`, wraps it in `AuthState`, and saves it locally.

#### [MODIFY] [StubAuthTokenProvider.kt](file:///home/yousef/Desktop/NutriScan/data/src/main/kotlin/iti/grad/nutriscan/data/remote/interceptor/StubAuthTokenProvider.kt) -> `AuthTokenProviderImpl.kt`
- Read the `AuthState` from `AuthTokenLocalDataSource`.
- Use AppAuth's `authState.performActionWithFreshTokens` inside a `suspendCancellableCoroutine`.
- This automatically handles **Token Refresh (1.4)**. If the access token is expired, AppAuth calls Keycloak's `/token` endpoint with the `refresh_token` and `client_id="mobile-api"`. If successful, the new state is saved, and the valid access token is returned. If `invalid_grant` occurs, the state is cleared.

### Presentation Layer

#### [MODIFY] [LoginViewModel.kt](file:///home/yousef/Desktop/NutriScan/presentation/src/main/kotlin/iti/grad/nutriscan/presentation/auth/login/viewmodel/LoginViewModel.kt)

- Observes the SideEffect containing `OidcAuthConfig`, uses the Android `AuthorizationService` to construct the `AuthorizationRequest`, and launches the intent.
- On Activity result, uses `AuthorizationService` to exchange the code for tokens.
- Maps the AppAuth `TokenResponse` into the pure `AuthTokens` domain model and passes it back to the ViewModel.
